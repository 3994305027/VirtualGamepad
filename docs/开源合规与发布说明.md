# 开源合规与发布说明

发布到公开平台（如哔哩哔哩）前，本文件列出的项目须逐项确认。

## 一、已具备的文件

| 文件 | 位置 | 作用 |
|---|---|---|
| LICENSE | 工程根目录 | 本项目自身代码的许可证全文（Apache-2.0） |
| NOTICE | 工程根目录 | 第三方依赖清单、改动说明、权限与免责 |
| licenses/Apache-2.0.txt | 工程根目录 | Apache-2.0 全文（同 LICENSE） |
| app/src/main/assets/licenses/ | assets 目录 | 供 App 内「关于」页展示的副本 |

## 二、依赖清单

| 组件 | 版本 | 许可证 |
|---|---|---|
| dev.rikka.shizuku:api | 13.1.5 | Apache-2.0 |
| dev.rikka.shizuku:provider | 13.1.5 | Apache-2.0 |
| dev.rikka.shizuku:aidl | 13.1.5 | Apache-2.0 |

未修改 Shizuku 源码，仅调用其接口（`newProcess` 采用反射调用，
原因是该方法在 13.1.5 中被声明为 private static）。

## 三、Apache-2.0 的三项义务

1. 随发布物附许可证全文 —— 已完成（LICENSE）
2. 保留原作者版权声明 —— 已完成（NOTICE）
3. 说明对源码的改动 —— 已完成（NOTICE 中的「改动说明」）

## 四、发布前自检

- [ ] APK 内不含未声明的第三方库
- [ ] 简介/详情页标注 Shizuku 及 Apache-2.0
- [ ] 标注运行条件（需 Shizuku 或 root、Android 8.0+）
- [ ] 标注权限用途，特别是 INTERNET 仅用于本机回环
- [ ] 免责声明：不读取/修改游戏内存，与游戏官方无关联
- [ ] 演示素材使用单机游戏或自有 Demo，不使用带反外挂的联机游戏
- [ ] 标题与简介不出现「连点」「自动」「脚本」「宏」等易触发审核的词
